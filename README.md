## 🚀  Main Projects

### 📧 Gmail / Email Checker

A beginner-level email validation program that checks whether an email follows several basic rules.

**Features:**
- Checks for "gmail.com"
- Checks for spaces
- Checks whether the email starts with a number
- Checks whether the first letter is lowercase
- Checks the position of "@"
