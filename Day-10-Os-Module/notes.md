Built a simple Python File Explorer using the os module. The program takes a folder path from the user, checks whether it exists, identifies whether it is a file or folder, lists all its contents, and counts the total number of files and folders. Through this project, I practiced os.listdir(), os.path.exists(), os.path.isfile(), os.path.isdir(), os.path.join(), shorthand if/else, loops, and user input, while learning how to work with file and folder paths in Python.
