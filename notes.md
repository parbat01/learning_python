### Day 7 — Python Learning Journey

Today I learned about **tuples, dictionaries, and sets** and practiced how they are used to store and manage different types of data. I learned how dictionaries work with key-value pairs, how sets handle unique values and remove duplicates, and how tuples store ordered and immutable data. I also practiced loops, functions, conditions, `match-case`, the `in` operator, string methods, `return`, variable scope, and debugging errors such as `NameError`. For today’s project, I built a **Student Data Analyzer** that stores student information and performs tasks such as searching students, calculating average marks, finding the highest and lowest marks, counting passed and failed students, and finding unique ages. This project helped me understand how Python can be used to **organize, process, and analyze structured data**, which is an important step toward my goal of becoming a **Data Scientist**.
